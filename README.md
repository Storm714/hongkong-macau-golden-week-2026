# 港澳双城 · 2026 国庆五天四晚路书

长沙出发，香港入境，澳门离开，经珠海返回长沙的两人五天四晚移动端旅行页面。

## 页面内容

- 五日逐时段行程与餐饮建议
- 出发前自动倒推待办清单
- 香港、澳门住宿片区与价位候选
- FlyAI 返回的高铁、酒店及部分景点跳转链接
- Leaflet 交互地图与离线文字降级
- 手机优先、桌面多列适配和减少动态效果支持

## 使用

直接打开 `index.html`。文字行程可离线阅读，地图瓦片、图片和外部查询链接需要联网。
